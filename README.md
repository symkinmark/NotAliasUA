# Аліас — українською 🇺🇦

Гра «Аліас» (Alias) для вечірок і компаній, з великим словником **українських слів**.
Форк [kubk/alias](https://github.com/kubk/alias) з доданою українською мовою.

## Що всередині

- **3 474 українських слова** — без дублікатів, усі перевірені вручну
- Інтерфейс повністю українською (мова за замовчуванням)
- Команди з іменами, лічильник балів і екран «Передайте телефон»
- Англійська та російська теж лишилися — перемикаються в налаштуваннях
- PWA: можна додати на головний екран телефона й грати офлайн
- Працює без бекенду — статичний сайт

## Словник

`src/lib/uk-words.json` — плоский масив рядків. Слова відібрані за правилами
класичного «Аліасу»: конкретні іменники, знайомі дієслова та прикметники,
жодних службових слів, власних назв чи абревіатур.

Теми: тварини, птахи, риби, комахи, рослини, їжа та кухня світу, напої, дім і
меблі, побутова техніка, кухонне приладдя, одяг і взуття, тканини та рукоділля,
інструменти, будівництво, сільське господарство, транспорт та інфраструктура,
тіло людини, медицина, професії, родина, спорт, ігри та іграшки, музика,
мистецтво, кіно й театр, наука, шкільні предмети, технології, космос,
географія, природа й погода, матеріали, місто, гроші та бізнес, військова й
морська тематика, час, свята, емоції, абстрактні поняття, дії, прикметники,
кольори, українська культура, військова та морська тематика, держава і політика,
право та доброчесність.

### Як додати або прибрати слова

Відредагуйте `src/lib/uk-words.json` — це звичайний JSON-масив. Нічого більше
змінювати не треба, гра підхопить зміни автоматично.

## Локальний запуск

```bash
pnpm install
pnpm dev
```

## Деплой на Vercel

Репозиторій уже налаштований (`vercel.json`, `base: "/"`).
Імпортуйте репо на [vercel.com/new](https://vercel.com/new) — Vercel визначить
Vite автоматично. Жодних змінних середовища не потрібно.
