# Аліас — українською 🇺🇦

Гра «Аліас» (Alias) для вечірок і компаній, з великим словником **українських слів**.
Форк [kubk/alias](https://github.com/kubk/alias) з доданою українською мовою.

## Що всередині

- **2 645 українських слів** — без дублікатів, усі перевірені вручну
- Інтерфейс повністю українською (мова за замовчуванням)
- Англійська та російська теж лишилися — перемикаються в налаштуваннях
- PWA: можна додати на головний екран телефона й грати офлайн
- Працює без бекенду — статичний сайт

## Словник

класичного «Аліасу»: конкретні іменники, знайомі дієслова та прикметники,
жодних службових слів, власних назв чи абревіатур.

### Як додати або прибрати слова

Відредагуйте `src/lib/uk-words.json` — це звичайний JSON-масив. Нічого більше
змінювати не треба, гра підхопить зміни автоматично.

## Локальний запуск

```bash
pnpm install
pnpm dev
```

## Деплой на Vercel

Репозиторій уже налаштований (`vercel.json`, `base: "/"`).
Імпортуйте репо на [vercel.com/new](https://vercel.com/new) — Vercel визначить
Vite автоматично. Жодних змінних середовища не потрібно.
