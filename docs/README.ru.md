Веб-игра в объяснение слов для компаний, оптимизированная для телефонов. Добавьте
на домашний экран для нативного опыта.

**Играть: https://notalias.vercel.app**

## Как играть

Команды по очереди объясняют слова своим игрокам с помощью подсказок и
ассоциаций, не называя само слово. За каждое угаданное слово команда получает
очко. Можно играть с одного телефона или создать комнату и играть сразу с
нескольких — все видят одни и те же слова, таймер и счёт.

## Возможности

- **Словарь**: тысячи украинских слов по темам и уровням сложности; английский и русский наборы тоже есть
- **Несколько телефонов**: комната с 4-значным кодом синхронизирует игру между устройствами
- **PWA**: можно «установить» на телефон и использовать как приложение
- **Плавные анимации**: интерфейс анимирован с помощью Framer Motion
